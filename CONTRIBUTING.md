Contributing Guidelines

Code quality

- You must keep the code clean and easy to understand.
- You should use meaningful names for variables and functions.
- You must avoid unnecessary changes to unrelated files.

Testing

- You must test your changes before committing.
- You should fix errors before submitting your changes.
- You must run the available checks before opening a pull request.

Git commits

- You should write clear and meaningful commit messages.
- You must review your changes before pushing.
- You must never commit passwords, API keys, or private credentials.

Documentation

- You should update documentation when changing existing functionality.
- You must keep instructions accurate and easy to follow.
